Examples:

CourseCompleted

BadgeEarned

CertificateIssued

VolunteerLogged

LeadershipVerified

RecommendationApproved

ResumeGenerated

PortfolioUpdated

JobApplied

ScholarshipMatched

InternshipAccepted

CollegeAdded

DreamSchoolChanged

CareerGoalUpdated

MentorAssigned
