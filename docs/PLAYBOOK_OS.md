# Playbook OS

Playbook is a Learner Intelligence Operating System.

It transforms evidence of growth into trusted records, knowledge graphs, opportunity matches, and personalized guidance.

---

## Current Milestone

Playbook Intelligence OS Alpha 1.0

---

## Core Idea

Playbook is built around the Playbook Record™.

Every meaningful action should improve or consume the Playbook Record.

---

## Core Services

### Compass

Guides the future.

Compass turns Playbook signals into explainable recommendations and next actions.

### Archivist

Remembers the past.

Archivist records development history, ship reports, logs, milestones, releases, and documentation memory.

### Cartographer

Maps the present.

Cartographer scans the project and auto-generates architecture maps, catalogs, and system documentation.

### Sentinel

Monitors platform health.

Sentinel checks that critical Playbook OS subsystems exist and remain connected.

## Guiding Rule

No feature ships unless it answers:

1. What engine owns the logic?
2. What graph or model does it enrich?
3. What event does it emit?
4. What Compass insight becomes possible?
5. What evidence is stored in the Playbook Record?
