# ADR-0001 — Playbook Record™

## Status

Accepted

## Decision

Playbook will use the Playbook Record™ as the canonical lifelong record.

## Why

Scholar data should not be trapped in isolated features.

## Alternatives Considered

- Separate data models per feature
- Profile-first architecture
- Resume-first architecture

## Consequences

All future features must improve or consume the Playbook Record™.
