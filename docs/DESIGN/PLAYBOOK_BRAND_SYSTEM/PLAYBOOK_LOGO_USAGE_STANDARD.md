# Playbook Logo Usage Standard

**Purpose:** Preserve Playbook logo identity across digital, mobile, profile, athletic, and physical use.  
**Owner:** Playbook Brand Governance  
**Last Updated:** July 30, 2026

## Canonical Assets

- Primary transparent application asset: `public/brand/playbook-logo.png`.
- Secondary compact candidate: `public/assets/logo-clean.png`.
- Historical source assets: `public/assets/logo-raw.png`, `logo.png`, `pb-logo-framed.png`, and `playbook-logo-new.png`.

Only the primary asset is treated as the current application source by `components/brand/PlaybookLogo.tsx`. Secondary and historical assets require brand review before new production use.

## Usage

Use the full primary logo for hero, launch, institutional, and high-recognition contexts. Use a certified compact mark for navigation, mobile, avatar, uniform, backpack, and merchandise contexts only after legibility and production review.

On light or dark backgrounds, preserve the asset's original color and transparency and provide sufficient contrast or a neutral clear field. Do not recolor, stretch, crop, rotate, redraw, animate destructively, add effects, separate elements, or place text inside the clear space.

## Integrity And Placement

Maintain intrinsic aspect ratio, minimum readable size, and clear space proportional to the logo mark. Physical placement requires substrate, embroidery, print, safety, licensing, and durability approval. Profile use must remain recognizable at small sizes and must not imply user verification.

## Accessibility

Digital logos use the accessible name “The Playbook — Run It!” when meaningful and empty alternative text when adjacent text already names the product.
