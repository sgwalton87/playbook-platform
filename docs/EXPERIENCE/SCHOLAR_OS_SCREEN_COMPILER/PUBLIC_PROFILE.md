# PUBLIC-PROFILE

**Purpose:** Consent-aware digital identity and achievement portfolio.  
**Primary role:** Scholar  
**Secondary roles:** Public viewer, mentor, institution

**Hierarchy:** Story -> verified achievements -> skills -> projects -> goals chosen for sharing -> opportunities sought -> community impact.  
**Components:** PB-PROFILE-001, PB-CARD-001, PB-BADGE-001, PB-JOURNEY-001.  
**Data:** Public projection only, evidence trust, visibility, expiry.  
**Actions:** Preview, change visibility, share, revoke link, inspect evidence.  
**Permissions:** Scholar owns publication; sensitive and private records are excluded by default.  
**Navigation:** `/u/[username]`; entry by governed share or public route.  
**APIs/Database:** Public projection service, never unrestricted Scholar Record.  
**States:** Loading, unpublished, unavailable, public success, owner permission, privacy withdrawal.  
**Responsive/Accessibility:** Single-column reading on mobile; portfolio grid on desktop; semantic sections, alt text, readable evidence labels.
