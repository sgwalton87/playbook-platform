# ACADEMY-COURSES

**Purpose:** Governed growth and learning environment.  
**Primary role:** Scholar  
**Secondary roles:** Scholar Athlete, counselor, institution

**Hierarchy:** Current learning path -> next module -> progress -> courses -> certifications -> evidence.  
**Components:** PB-COURSE-001, PB-PROGRESS-001, PB-BADGE-001, PB-CARD-001.  
**Data:** Course identity, enrollment, module progress, completion evidence, certificate authority.  
**Actions:** Continue learning, choose path, submit reflection, review certificate evidence.  
**Permissions:** Enrollment and content access; supporters receive scoped progress only.  
**Navigation:** `/courses`; course detail and certificate exits.  
**APIs/Database:** Course catalog, progress, evidence, certification adapters.  
**States:** Loading, no enrollment, content error, active success, locked course, private progress.  
**Responsive/Accessibility:** Mobile supports complete course workflow; desktop adds path overview; media includes captions and transcripts.
