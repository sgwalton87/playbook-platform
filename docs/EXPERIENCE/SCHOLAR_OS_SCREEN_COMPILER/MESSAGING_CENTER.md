# MESSAGING-CENTER

**Purpose:** Trusted relationship communication network.  
**Primary role:** Scholar  
**Secondary roles:** Parent, mentor, coach, counselor, peer

**Hierarchy:** Safety and relationship context -> conversations -> unread priority -> message content -> actions.  
**Components:** PB-NAV-001, PB-MESSAGE-001, PB-PROFILE-001.  
**Data:** Participant identity, relationship authority, consent, thread, delivery and safety state.  
**Actions:** Read, reply, start permitted thread, report, block, manage consent.  
**Permissions:** Valid relationship and messaging scope required; minors receive applicable safeguards.  
**Navigation:** `/messages`; thread deep links preserve inbox return.  
**APIs/Database:** Messaging boundary, relationship graph, safety and audit services.  
**States:** Loading, no conversations, send failure, success, relationship restricted, safety/privacy state.  
**Responsive/Accessibility:** Mobile inbox-to-thread flow; desktop split view; live regions announce delivery and errors without exposing private text.
