# SCHOLAR-ATHLETE-HOME

**Purpose:** Academic-first athletic development journey.  
**Primary role:** Scholar Athlete  
**Secondary roles:** Parent, coach, counselor, institution

**Hierarchy:** Education -> career -> athletics -> development.  
**Data:** Academic eligibility, courses, credits, graduation and college readiness, athletic identity and history, recruiting readiness, goals, verified achievements, opportunity pathways.  
**Components:** PB-NAV-001, PB-MODULE-001, PB-PROGRESS-001, PB-JOURNEY-001, PB-BADGE-001, PB-OPPORTUNITY-001.  
**Actions:** Review eligibility evidence, confirm development goal, explore pathway, share scoped profile.  
**Permissions:** Separate academic, athletic, recruiting, and supporter visibility.  
**Navigation:** `/scholar-athlete-os`; preserves return context across academic and opportunity views.  
**APIs/Database:** Scholar Record, academic evidence, athletic evidence, consent, opportunities.  
**States:** Loading, no sport selected, evidence unavailable, success, role restricted, recruiting privacy.  
**Responsive:** Mobile leads with academic status and next action; desktop compares readiness paths.  
**Accessibility:** Tables provide linear alternatives; status uses text and icons; all actions are keyboard accessible.
