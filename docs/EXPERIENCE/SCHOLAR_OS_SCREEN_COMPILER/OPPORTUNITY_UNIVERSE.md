# OPPORTUNITY-UNIVERSE

**Purpose:** Evidence-backed discovery across scholarships, internships, programs, competitions, and careers.  
**Primary role:** Scholar  
**Secondary roles:** Scholar Athlete, parent, mentor, counselor

**Hierarchy:** Search intent -> verified matches -> eligibility and deadline -> reason and evidence -> action.  
**Components:** PB-OPPORTUNITY-001, PB-COMPASS-001, PB-PROGRESS-001, PB-CARD-001.  
**Data:** Provider identity, provenance, eligibility, expiry, geography, cost, readiness, confidence.  
**Actions:** Search, compare, save, assess eligibility, request support, begin governed application.  
**Permissions:** Opportunity visibility and sensitive eligibility inputs are purpose-bound.  
**Navigation:** `/opportunities`; detail, toolkit, application, and support exits.  
**APIs/Database:** Certified opportunity sources, search projection, saved state, application handoff.  
**States:** Loading, no verified match, provider failure, success, eligibility restricted, personalization privacy.  
**Responsive/Accessibility:** Mobile uses filter sheet and comparison summary; desktop supports comparison; filters and results have semantic labels.
