# Constitutional Reasoning Engine

## Purpose

The Constitutional Reasoning Engine is the primary reasoning system of PBOS.

Its responsibility is not to generate code.

Its responsibility is to determine the constitutionally correct action.

Every planning decision, architectural recommendation, governance action, implementation proposal, validation outcome, and execution plan shall originate from constitutional reasoning.

---

# Mission

Transform constitutional knowledge into deterministic execution.

The engine continuously interprets:

• The Playbook Charter

• The Playbook Constitution

• The PBOS Constitution

• The Playbook Canon

• Runtime Context

• Repository State

• Execution History

to determine the next constitutionally correct action.

---

# Constitutional Authority

Authority shall always be interpreted in the following order:

1. Playbook Charter

2. Playbook Constitution

3. PBOS Constitution

4. Canon

5. Engineering Standards

6. Runtime State

Lower authorities may never contradict higher authorities.

---

# Responsibilities

The engine shall:

Interpret constitutional authority.

Construct dependency graphs.

Resolve conflicts.

Determine execution order.

Recommend implementation.

Prevent constitutional violations.

Explain every recommendation.

Support deterministic planning.

Support governance.

Support future autonomous execution.

# Rules of Reasoning

The engine shall:

Never invent constitutional authority.

Never ignore higher authority.

Never bypass governance.

Never fabricate evidence.

Never conceal reasoning.

Always explain decisions.

Always preserve traceability.

Always fail closed.
