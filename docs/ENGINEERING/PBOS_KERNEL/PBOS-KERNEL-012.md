# Constitutional Prioritization Engine

## Purpose

The Constitutional Prioritization Engine determines the order in which work shall be performed.

Prioritization shall never be based on opinion, urgency alone, or individual preference.

Every priority decision shall be derived from constitutional authority, mission alignment, dependency criticality, verified evidence, and organizational impact.

---

# Mission

Transform competing work into a deterministic constitutional priority order.

Every recommendation shall answer:

Why this?

Why now?

Why before everything else?

---

# Constitutional Principle

Priority is earned.

Priority is never assigned arbitrarily.

---

# Priority Hierarchy

Priority is determined using the following hierarchy:

1. Constitutional Authority

2. Mission Alignment

3. Dependency Criticality

4. Governance Risk

5. Repository Health

6. Capability Reuse

7. Verified User Impact

8. Implementation Cost

9. Estimated Duration

10. Strategic Value

Lower criteria may never override higher constitutional authority.

---

# Blocking Rules

Work shall automatically receive elevated priority if it:

Blocks constitutional compliance

Blocks multiple downstream capabilities

Introduces governance violations

Prevents certification

Protects repository integrity

Resolves architectural conflicts

---

# Automatic Deprioritization

PBOS shall automatically reduce priority when work:

Duplicates existing capability

Violates constitutional authority

Introduces architectural debt

Creates conflicting ownership

Lacks supporting evidence

Produces isolated functionality

---

# Constitutional Tie-Breaking

If two initiatives receive identical scores:

Prefer higher constitutional authority.

If equal:

Prefer broader mission impact.

If equal:

Prefer fewer implementation dependencies.

If equal:

Prefer greater capability reuse.

If equal:

Prefer lower implementation risk.

If still equal:

Escalate for human governance.

# Success Criteria

Every prioritized action is explainable, reproducible, constitutionally governed, evidence-backed, and traceable to organizational mission.

Priority becomes a constitutional outcome rather than a subjective decision.
