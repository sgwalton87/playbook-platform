## Mission
Finish and connect the existing Playbook Record, Compass, Scholar Record resume/portfolio, personal statement coach, and course journey. The Scholar should have one persistent profile, not four isolated copies. Each experience MUST consume or enrich an authorized projection of the Playbook Record. No duplicate achievement, verification, transcript, reward, course, or profile authorities.

## Canonical data flow
Verified/claimed Scholar Record events -> authorized role/age-filtered Scholar projection -> (a) Compass recommendation context, (b) resume/portfolio section selection, (c) personal statement evidence prompts, (d) courses readiness and progress. Course completion, approved submissions and documented achievements write back to existing Record events/evidence, not to second parallel profiles. Every derived output carries source IDs, timestamps, review status and revision.

## Program gates — execute in dependency order
**SJ-00 Record projection and privacy authority, P0.** Map profile, academics, experience, volunteer service/hours, leadership, achievements/awards, courses, credentials, skills, athletics, verified evidence, reflections and outcomes. Keep claimed/unverified entries visually distinct from verified ones. Audit age/guardian permissions, self-authored public/private selections, RLS, deletion, export and erasure. Contract-test ownership and deny cross-scholar leakage. Deliver a versioned, typed read adapter, NOT a new master table.

**SJ-01 Compass wiring, P0.** Replace page-owned course/trust inputs with authorized Scholar Record adapter. Explain why recommendations were generated; link each reason to permitted evidence; version calculations, freshness and missing-data statements; never turn trust fallback into a fabricated fact. Implement accept/defer/dismiss/ask-network actions through existing events and workspace authority. Acceptance: controlled Scholar can act on recommendation, reload, see durable state; unrelated Scholar denied. Support manual override/appeal and no autonomous sensitive decisions.

**SJ-02 Scholar Record Builder & Resume, P0.** One editable profile-to-record flow for service, leadership, experience, awards, education, courses, skills, certificates and evidence. Scholar chooses which entries to publish; attribution, duration, dates, hours, outcome and verification statuses preserved. Resume templates tailored to employer, college and scholarship; export accessible PDF and optional printable view; downloadable file matches preview and never includes private evidence by default. Add evidence-based preview, edit, archive, revise. No fabricated awards/hours.

**SJ-03 Governed External Share, P0.** Extend currently NIL-only authorization after policy approval for employer and educational-institution audiences. Scholar opts in per packet and recipient/purpose with expiry, revocation, access event, read-only signed unguessable token, scoped minimum data and rate limiting. A minor's sharing needs age/guardian authority. Recipient can view without creating a Playbook account *only* when explicitly granted; no transcript, private document or sensitive field by default. Test revoked/expired/unlisted packet denies; link sharing is not automatically publishing everything. Consent and audit events are mandatory.

**SJ-04 Personal Statement Coach & Writing Module, P0.** Draft/edit/revise personal statements for college, employment, scholarship and program applications. Guided prompts grounded in self-authored experiences, achievements and reflections with traceable optional sources. Scholar controls tone, target, word count, version, consent and sharing. Offer clarity/structure/grammar/voice coaching and a provenance/unsupported-claim review; never invent hardships, identity, awards, scores or quotes. Protect minors' writing, prohibit unsolicited external sending, store drafts owner-scoped and allow export. Tests for private drafts, save/reload, version rollback, citation boundaries, profanity/trauma sensitivity, full mobile editing and screen-reader support.

**SJ-05 Courses End-to-End, P0.** Certify discover/search -> enroll/continue -> lesson modules -> saved draft and quiz server evaluation -> progress -> completion -> governed credential/badge/reward -> Playbook Record evidence -> Compass and resume refresh. Do not expose private checkpoint keys or double-issue XP; retry-safe completion, resume after session interruption, mobile/slow-network state. Accessibility, empty/error/loading and content review gates. Preserve existing rich authored leadership/civic curriculum; audit publication readiness for each course, not just list presence.

**SJ-06 Integration and launch, P0.** End-to-end scholar and age-appropriate guardian matrix: new signup, verified email, onboarding/resume, service entry, evidence upload, course module, award, Compass action, resume download, external sharing/revocation, statement draft/export, re-login. Run isolated DB + web mobile smoke + privilege/RLS + PDF accessibility and signed-link security + rollback. Release by feature flag and audited approved SHA; founder authorizes production migration and deploy. No false "live" claims.
