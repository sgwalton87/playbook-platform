# PBOS Mission Intelligence Engine Implementation

**Purpose:** Document deterministic mission-alignment assessment.  
**Owner:** Playbook OS Engineering  
**Last Updated:** July 30, 2026

`pbos/intelligence/mission/` defines mission objectives, strategic goals, impact, and weighted priority. It requires mission ownership, source evidence, and at least one governed goal. Scores are bounded and deterministic. Alignment informs recommendations but cannot define mission or select work.
