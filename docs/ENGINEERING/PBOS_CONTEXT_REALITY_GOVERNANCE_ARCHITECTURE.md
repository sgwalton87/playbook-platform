# PBOS Context Reality Governance Architecture

**Purpose:** Establish whether PBOS has a trustworthy current operating baseline.  
**Owner:** Playbook OS Engineering  
**Last Updated:** July 30, 2026

`ContextRealitySnapshot` binds repository, commit, branch, working-tree content, runtime, governance, artifact inventory, architecture inventory, timestamp, and digest. Validation rejects dirty state, identity mismatch, incomplete inventory, missing governance, and digest corruption.

Refresh remains owned by the existing Context lifecycle. A candidate requires reconciliation, request, independent decision, and evidence before canonical refresh. Observation cannot silently become refresh authority.
