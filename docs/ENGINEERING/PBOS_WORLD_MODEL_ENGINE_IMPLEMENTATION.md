# PBOS World Model Engine Implementation

**Purpose:** Document the machine-readable ecosystem snapshot foundation.  
**Owner:** Playbook OS Engineering  
**Last Updated:** July 30, 2026

`pbos/intelligence/world-model/` models governed entity kinds, relationships, dependencies, organization scope, evidence, time, confidence, and digest. Duplicate entities, evidence-free entities, and unresolved relationships fail closed. The snapshot does not replace source-system truth.
