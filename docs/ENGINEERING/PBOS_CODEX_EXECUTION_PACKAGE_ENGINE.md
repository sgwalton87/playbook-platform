# PBOS Codex Execution Package Engine

## Purpose

Convert an eligible constitutional plan into an immutable implementation contract.

## Contract

Packages define mission, current state, architecture context, dependencies, required changes, risk controls, testing, documentation, acceptance criteria, recommendation identity, and human approval requirements.

## Integrity

Package validation requires identity, mission, human approval, validation criteria, completion criteria, and a matching content digest. Modified packages are rejected.

## Authority

Package generation does not authorize work. The Constitutional Planner remains selection authority and the Kernel remains execution authority.
