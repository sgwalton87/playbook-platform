# PBOS Agent Governance Implementation

**Purpose:** Document agent action admission controls.  
**Owner:** Playbook OS Engineering  
**Last Updated:** July 30, 2026

`pbos/agents/governance/` binds agent identity, owner, model, organization scope, permissions, expiry, purpose, data boundaries, evidence, and trace identity. Self-authorization, permission mutation, self-certification, and governance change are permanently prohibited. Every admitted action still requires human approval.
