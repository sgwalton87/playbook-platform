# Executive Summary

Defines the canonical contract for APIs.

# API Schema

- API ID
- Name
- Endpoint
- Method
- Purpose
- Inputs
- Outputs
- Authentication
- Authorization
- Rate Limits
- Errors
- Events
- Owner

# Principles

APIs SHALL be versioned, documented, observable, and secure.

# Codex Implementation Contract

Codex SHALL NOT consume undocumented APIs or generate endpoints without canonical identifiers.
