# Executive Summary

Defines the canonical dashboard architecture for every Playbook Operating System.

## Purpose

Dashboards are mission-control interfaces for each role.

# Canonical DASHBOARD Schema

- Dashboard ID
- Operating System
- Purpose
- Primary Users
- Widgets
- Cards
- Quick Actions
- Notifications
- Metrics
- AI Insights
- Personalization
- Permissions
- Data Sources
- Analytics
- Definition of Done

# Dashboard Principles

- One dashboard per Operating System.
- Every widget must support a user decision.
- Decorative widgets are prohibited.
- AI augments, not replaces, human judgment.

# Codex Implementation Contract

Codex SHALL ensure each dashboard maps to one Operating System and references only canonical widgets, pages, and workflows.
