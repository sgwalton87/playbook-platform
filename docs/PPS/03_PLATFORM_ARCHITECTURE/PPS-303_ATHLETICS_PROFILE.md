# Athletics Profile

## Purpose

The Athletics Profile preserves the learner-athlete journey.

## Supported Information

Includes:

- athletic development;
- teams;
- achievements;
- statistics;
- training;
- recruiting information;
- international athletics experiences.

## Global Athlete Support

The Athletics Profile supports:

- high school athletes;
- college athletes;
- professional athletes;
- international athletes;
- athletes transitioning across countries.

## Governance

PBOS does not:

- determine eligibility;
- select teams;
- guarantee recruiting outcomes;
- make roster decisions.

## Definition of Done

Athletics learner profile established.
