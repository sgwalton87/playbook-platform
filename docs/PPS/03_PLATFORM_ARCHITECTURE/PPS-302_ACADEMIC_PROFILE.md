# Academic Profile

## Purpose

The Academic Profile preserves the learner's educational journey.

## Supported Information

Includes:

- institutions;
- coursework;
- academic interests;
- pathways;
- milestones;
- academic goals;
- verified achievements.

## Principles

Academic information must:

- preserve evidence;
- identify sources;
- distinguish verified and self-reported information;
- remain learner-owned.

## Governance

PBOS does not make admissions, graduation, or institutional decisions.

## Definition of Done

Academic learner profile established.
