Purpose

The Canonical Document Registry establishes the single authoritative document for each major domain of the Playbook Platform.

PBOS, AI agents, automation, contributors, and maintainers shall consult this registry before creating, modifying, or referencing documentation.

If multiple documents describe the same concept, this registry determines which document is authoritative.

Document Rules

One domain shall have one canonical owner.

Duplicate documentation should reference the canonical source.

Historical documentation shall not become canonical.

Deprecated documentation shall never become canonical.

Architecture decisions belong only in ADR.

Implementation guidance belongs only in Engineering.

Platform governance belongs only in PPS.

PBOS Responsibilities

Resolve canonical ownership.

Detect duplicate documentation.

Recommend consolidation.

Validate document locations.

Maintain repository consistency.

Prevent conflicting governance.
