# Builder Journal

Today we moved The Playbook from generic signup/onboarding toward intentional role-based entry points.

The most important strategic decision was to stop treating every user as a Scholar variation. Scholar, Scholar-Athlete, Brand Partner, Family, Mentor, Educator, Coach, Recruiter, Admissions, Employer, and TAY need different onboarding experiences because they create different kinds of value inside the platform.

We also reaffirmed that Brand Partner is not a future idea. It is core to the Scholar-Athlete engine and must be available now.
