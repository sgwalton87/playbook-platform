# Purpose

Define the constitutional architecture governing execution context throughout the Playbook Platform.

Execution context represents the complete constitutional environment in which execution occurs.

Every execution shall possess explicit context.

---

# Scope

Applies to:

- Commands
- Workflows
- Events
- Automations
- Background jobs
- Intelligence operations
- Administrative operations
- Future execution technologies

---

# Constitutional Principles

Execution context shall be:

- Explicit
- Immutable during execution
- Traceable
- Secure
- Observable
- Portable
- Governed

Hidden execution context is constitutionally prohibited.

---

# Context Model

Execution context includes:

- Constitutional identity
- Request identity
- Actor identity
- Organization identity
- Authorization
- Permissions
- Execution purpose
- Execution environment
- Time
- Provenance

---

# Context Propagation

Execution context shall propagate across:

- Workflow boundaries
- Event boundaries
- Service boundaries
- Process boundaries
- Distributed execution
- Recovery operations

Context shall remain complete and verifiable.

---

# Context Integrity

Execution shall terminate if constitutional context:

- Cannot be verified
- Becomes inconsistent
- Loses authorization
- Becomes corrupted
- Violates governance requirements

Execution shall fail closed.

---

# Governance

Execution context constitutes constitutional infrastructure.

Every execution depends upon context integrity.
