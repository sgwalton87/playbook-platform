# Playbook Philosophy

Playbook optimizes for opportunity, not attention.

## Core Beliefs

- Opportunity over engagement.
- Verified growth over vanity metrics.
- The Scholar owns their story.
- AI assists; humans decide.
- Build once, reuse everywhere.
- Every feature should strengthen the Scholar Record.
- Playbook should equip families, educators, mentors, and communities — not replace them.

## Product Standard

If a feature does not create measurable opportunity for Scholars, it does not belong in Playbook.
