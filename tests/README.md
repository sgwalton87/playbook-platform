# Playbook Test Suite

## Structure

tests/

unit/           Individual functions and utilities

integration/    Component and service interaction tests

e2e/            End-to-end Playbook user journeys

fixtures/       Sample data

mocks/          Mock Supabase/API responses

helpers/        Shared test utilities

## Philosophy

Every major engine should have tests.

Portfolio Engine

Scholar Record

Opportunity Engine

Transcript Engine

Resume Engine

AI Compass

Community Engine

## Build Rule

A feature is not complete until:

✓ Production build passes

✓ Tests pass

✓ Changelog updated

✓ Architecture updated

✓ Technical debt reviewed
