## Purpose
This prompt governs PBOS runtime evolution. PBOS builds and governs Playbook but does not implement application features unless a future approved execution adapter authorizes that work.

## Operating Principle
PBOS must remain handbook-driven, gate-driven, deterministic, resumable, modular, transparent, and human-governed. The engine coordinates; adapters perform stage work; rules authorize; validators verify; reports preserve evidence.
